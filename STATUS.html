Test scope

2026-09-14: 14 repeatable support probes passed on private Herdr 0.9.0 / protocol 22 servers with temporary repos, attached UIs, and agent stubs. Probes check both working paths and known restrictions; a passing probe does not imply full feature support. User resources unchanged; other backends not retested.

2026-09-15 status routing: all 15 support probes and the private-server adapter runner passed on macOS without status-variable removal or a forced native-hook backend. The new target probe checks registration, moved and closed terminals, endpoint separation, and server lifetimes. Native protocol reports map done to idle. Agent tests use stubs, not real conversation replay. Linux was not retested for this change.

2026-09-15 recovery: restart and partial-failure probes and the private-server adapter runner passed on macOS. The earlier restart probe created a duplicate parent name after Herdr restored its workspace labels. Full error reporting now exposes that cause. Tests retain native restored panes, reject old ownership and cleanup commands, and verify missing parents, repeat restore, and recovery-data retention. Linux and real conversation replay were not retested.

Earlier unit baseline (2026-09-14): 1,733 passed, 0 failed, 18 ignored; 1 live-clipboard test excluded. Per-row unit counts are subsets of this total. Full private-server Herdr integration runner passed, including workspace operations, caller identity, launch ownership, and six cleanup races.

Not verified: remote PR/MR creation, real agent conversation replay, Codex fork, real sandbox guests, guest-to-Herdr RPC, and clipboard transfer. No Docker, Podman, or Lima CLI is installed. User clipboard access was skipped.

Main gaps: session mode and Workmux sidebar are blocked; focus does not clear status; external multi-agent calls reject a parent workspace. Popup scripts need an explicit parent; last-agent toggle needs a native caller.
