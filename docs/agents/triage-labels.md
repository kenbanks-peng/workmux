# Triage labels

Use this mapping when a skill names a triage role.

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | A maintainer must assess the issue. |
| needs-info | needs-info | More information is needed from the reporter. |
| ready-for-agent | ready-for-agent | The specification is complete; an agent can implement it. |
| ready-for-human | ready-for-human | A human must implement it. |
| wontfix | wontfix | The issue will not be implemented. |

To use different labels, edit the Tracker label column.
