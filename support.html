Test scope

2026-09-14: light checks on a private Herdr 0.9.0 / protocol 22 server with temporary repos and agent stubs. User resources unchanged; tmux not retested.

Unit tests: 1,734 passed, 0 failed, 18 ignored. Full Herdr integration runner not run.

Skipped live tests: popups, PR/MR creation, continue/fork, last-agent toggle, forced reaping, sandbox, host RPC, and clipboard.

Main gaps: default status hooks lose updates; external multi-agent calls cannot set the required parent workspace. Workarounds and other limits are noted above.

Sources: status target validation · agent launch and status variables · add restrictions · diff and patch actions · agent reaping · sandbox supervisor · WezTerm adapter · kitty adapter · shared backend operations · Herdr support record. Planned features and unrun tests are not counted as verified support.
